Entry for make.fun's "Promote make.fun's make-your-own-bounty post on X" bounty ($250, top 50 share it). The post itself is the entry: one post of our own on X quoting make.fun's post (https://x.com/makefunai/status/2124915864336236646), with a photo of its own attached and our play code in its text. Places go by the post's replies + reposts + quotes at the deadline.

`POST.json` holds the post's address. `main.ts` copies it to `/output/POST.json`, which is all the program has to do.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
